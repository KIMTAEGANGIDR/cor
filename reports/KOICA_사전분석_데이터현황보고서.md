## 1. 프로젝트 개요

### 1.1 목적
인도네시아 법제처(peraturan.go.id)의 법률 문서를 수집, OCR 처리, 구조화하여 검색 가능한 법률정보시스템을 구축한다.

### 1.2 사업 범위
- **기준 시점:** 2024년 12월 31일 peraturan.go.id 등록 데이터
- **1차 구축 목표:** 150,000 페이지 (수원기관 협의로 조정 가능)
- **대상 법령:** 35,424건 (비대상 제외)

### 1.3 품질 기준
- KOICA "zero defect tolerance" 품질 표준 준수
- OCR 정확도 95% 이상 목표
- 모든 문서 구조 파싱 가능

## 3. KOICA 기준 차이 원인 분석

### 3.1 미충족 항목 상세

#### 3.1.1 PERPPU (대체법령) - 15건 미충족

| 원인 | 건수 | 상세 |
|------|------|------|
| **사이트 페이지 미존재** | 15 | peraturan.go.id에 상세 페이지 자체가 없음 |

**해당 문서 목록:**
- 1946~1949년 구(舊) PERPPU 문서
- URL 접근 시 404 또는 빈 페이지 반환
- 해당 시기 법령은 디지털화 이전 문서로 추정

**근거:**
```
크롤링 시도: 202건 성공 / 0건 실패
사이트 검색 결과: 217건 표기
실제 접근 가능: 202건
차이: 15건 (사이트에 목록만 있고 상세 페이지 없음)
```

#### 3.1.2 UUDRT (긴급법령) - 2건 미충족

| 원인 | 건수 | 상세 |
|------|------|------|
| **사이트 표기 vs 실제 차이** | 2 | 사이트 176건 표기, 실제 175건만 접근 가능 |

**분석:**
- KOICA 기준: 177건
- 사이트 표기: 176건 (이미 1건 차이)
- 실제 크롤링: 175건 (추가 1건 비공개/비정상)
- 총 미충족: 2건

**추정 원인:**
1. KOICA 기준 시점(2024.12.31) 이후 사이트 데이터 변경
2. 일부 문서 비공개 전환 또는 삭제

#### 3.1.3 UUDS (임시헌법) - 1건 미충족

| 원인 | 건수 | 상세 |
|------|------|------|
| **공개 카테고리 부재** | 1 | 독립 유형으로 검색/접근 불가 |

**분석:**
- KOICA 기준에 UUDS 1건 명시
- peraturan.go.id에서 "UUDS" 카테고리 없음
- 다양한 검색어로 탐색 시도 → 결과 없음
- `uuds-no-1-tahun-1950` 등 추정 URL 접근 → 404 반환

**추정 원인:**
- UUDS(1950년 임시헌법)는 역사적 문서로, 현행 법령 DB와 별도 관리 가능성
- 또는 UUD 카테고리 내 포함되어 있을 가능성 (추가 확인 필요)

1. **PERPPU 15건 원본 제공 요청**
   - 1946~1949년 PERPPU 원본 PDF 디지털화 여부
   - 대체 보관 기관 안내

2. **UUDS 접근 방법 문의**
   - 임시헌법(UUDS 1950) 공개 여부
   - 별도 카테고리 또는 접근 경로

3. **UUDRT 2건 누락 사유 확인**
   - 사이트에서 삭제된 2건의 식별 정보
   - 복구 가능 여부
