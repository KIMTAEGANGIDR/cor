## 5. 파이프라인 아키텍처

### OCR 엔진 앙상블 (v2 하이브리드)
```
PDF 입력
    ↓
텍스트 추출 (PyMuPDF)
    ↓
품질 점수 계산
    ├── 품질 >= 0.92 → 텍스트 사용 (빠름)
    └── 품질 < 0.92 → 이미지 → OCR 앙상블
                            ├── Surya OCR (GPU, 메인)
                            ├── PaddleOCR (GPU, 보조)
                            └── Tesseract (CPU, 백업)
    ↓
결과 선택 (confidence 기반)
    ↓
구조 파싱 → XML 변환
```

**장점:**
- 3개 OCR 엔진 앙상블로 정확도 향상
- GPU 가속으로 처리 속도 개선
- 원본 PDF 텍스트 품질 자동 감지 및 OCR 전환
