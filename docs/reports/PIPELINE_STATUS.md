## 5. 파이프라인 v2 (하이브리드) 변경사항

### 기존 방식 (v1)
```
텍스트 추출 → 전략 결정 (TEXT/HYBRID/OCR) → 각각 처리
```

### 신규 방식 (v2 하이브리드)
```
텍스트 추출 → 품질 점수 계산
    ↓
품질 >= 0.92 → 텍스트 사용 (빠름)
품질 < 0.92 → 이미지 → OCR (일관성)
```

**장점:**
- 원본 PDF 텍스트 오류 자동 감지 및 OCR 전환
- 일관된 품질 보장
- MANUAL_REVIEW 케이스 대폭 감소
