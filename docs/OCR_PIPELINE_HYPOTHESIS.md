## 핵심 가설

### H1: 연도별 품질 차이
**가설**: 오래된 문서(1940-1970년대)는 스캔 품질이 낮아 OCR 정확도가 현저히 떨어질 것이다.
- **근거**: 타자기 인쇄, 저해상도 스캔, 종이 변색
- **예상**: 1940-60s < 70%, 1970-80s 70-85%, 1990s+ > 85%
- **검증 방법**: 연대별 샘플링 테스트
- **상태**: 🔄 테스트 중

### H2: 문서 유형별 품질 차이
**가설**: UU(법률)가 가장 품질이 높고, PERMEN(부령)은 다양성이 클 것이다.
- **근거**: UU는 공식 인쇄, PERMEN은 부처별 다양한 포맷
- **검증 방법**: 유형별 품질 점수 분포 비교
- **상태**: ⏳ 대기

### H3: LLM 교정 효과
**가설**: LLM 교정은 규칙 기반 교정보다 5-15% 추가 품질 향상을 가져올 것이다.
- **근거**: 문맥 이해로 규칙이 못 잡는 오류 교정
- **조건**: WARNING 등급(90-95%) 문서에서 특히 효과적
- **상태**: ⏳ 대기

### H4: 95% 기준의 적절성
**가설**: KOICA 95% 기준은 현실적이며, 대부분의 현대 문서(2000년대+)에서 달성 가능하다.
- **근거**: 현대 문서는 디지털 인쇄, 고품질 스캔
- **위험**: 1950-70년대 문서는 기준 미달 가능성 높음
- **상태**: ⏳ 대기

## 파이프라인 목적

### 1차 목표: OCR 품질 검증
- 36,000+ PDF 문서의 OCR 가능성 평가
- 연도/유형별 품질 패턴 파악
- KOICA 95% 기준 충족 가능 문서 비율 추정

### 2차 목표: 자동화 파이프라인 구축
- Surya OCR → 규칙 교정 → 품질 검증 → (필요시) LLM 교정
- 인간 개입 최소화 (자동 승인 비율 극대화)
- 처리 속도: PDF당 평균 60초 이내

### 3차 목표: 품질 보증 체계
- 등급별 분류: PASS (≥95%), WARNING (90-95%), FAIL (<90%)
- 자동 승인 / LLM 교정 / 인간 검토 분기
- 모든 결과 로깅 및 추적 가능
