# Header Cluster Agent - 분류 계획 및 가설

## 1. 목적

LLM OCR 파이프라인의 오류를 줄이기 위해 헤더 이미지의 시각적 패턴을 사전 분류하고,
각 패턴에 최적화된 OCR 전략을 적용한다.

## 2. 핵심 가설

### H1: 시각적 패턴 = 법령 유형 (Jenis)
**가설**: 같은 법령 유형(UU, PP, Perpres 등)은 동일한 헤더 템플릿을 사용한다.

**검증 방법**: 클러스터의 jenis 순수도 측정
- 순수도 ≥ 80%: 가설 지지
- 순수도 < 50%: 가설 기각

**현재 상태**:
- [ ] 미검증
- [ ] 지지됨
- [ ] 기각됨
- [ ] 부분 지지

**검증 결과**: (자동 업데이트)

### H2: 시각적 패턴 = 연도 (Tahun)
**가설**: 문서 포맷은 시기별로 변경되며, 같은 시기 문서는 비슷한 헤더를 갖는다.

**검증 방법**: 클러스터의 연도 범위(span) 측정
- 스팬 ≤ 5년: 가설 지지
- 스팬 > 10년: 가설 기각

**현재 상태**:
- [ ] 미검증
- [ ] 지지됨
- [ ] 기각됨
- [ ] 부분 지지

**검증 결과**: (자동 업데이트)

### H3: 시각적 패턴 = 스캔 품질
**가설**: 스캔 시기/장비에 따라 문서 품질이 다르며, 이것이 클러스터에 반영된다.

**검증 방법**: 클러스터별 평균 밝기, 대비 분석
- 품질 그룹 분리 확인

**현재 상태**:
- [ ] 미검증

**검증 결과**: (자동 업데이트)

## 3. 클러스터링 파라미터

### 3.1 특징 추출
| 특징 | 차원 | 가중치 | 설명 |
|------|------|--------|------|
| dHash | 64 | 1.0 | 이미지 구조/윤곽 |
| 히스토그램 | 48 | 1.0 | RGB 색상 분포 |
| 평균 밝기 | 1 | 1.0 | 스캔 품질 지표 |
| 종횡비 | 1 | 1.0 | 헤더 영역 비율 |

### 3.2 클러스터 수 결정
- **목표**: 200개 클러스터 (법령 유형 × 시기 조합)
- **조정 기준**:
  - 평균 클러스터 크기 < 50: 클러스터 수 감소
  - 평균 순수도 < 70%: 클러스터 수 증가

## 4. LLM OCR 전략 적용 계획

### Phase 1: 클러스터 대표 샘플 추출
1. 각 클러스터에서 중심에 가장 가까운 샘플 1개 선택
2. 총 200개 대표 샘플 생성

### Phase 2: LLM 프롬프트 생성
1. 각 대표 샘플을 LLM에 제공
2. 해당 패턴에 최적화된 OCR 지시문 생성
3. 클러스터별 프롬프트 저장

### Phase 3: 실제 OCR 적용
1. 새 문서 → 클러스터 할당 (최근접 이웃)
2. 해당 클러스터의 프롬프트로 OCR 실행

## 5. 수정 프로세스

### 5.1 가설 수정
가설 검증 결과에 따라:
- 지지됨: 해당 기준을 LLM 프롬프트에 명시적으로 포함
- 기각됨: 해당 기준 제외, 대안 탐색
- 부분 지지: 조건부 적용 (특정 하위 그룹에만)

### 5.2 클러스터 수 조정
```
IF 평균_순수도 < 70%:
    n_clusters *= 1.5
ELIF 평균_클러스터_크기 < 30:
    n_clusters *= 0.7
```

### 5.3 특징 가중치 조정
상관관계 분석 결과에 따라:
- 높은 상관관계 특징: 가중치 증가
- 낮은 상관관계 특징: 가중치 감소 또는 제거

## 6. 성공 지표
